# Kings Data Science Project (Sep 2025)

## Overview

This project was developed as part of the application process for the Associate Data Scientist position with the Sacramento Kings. The primary objective is to utilize anonymized data sources to recommend international basketball players for the scouting team to focus on.

## Project Structure

project-work/
    api_data_files/ # Raw data fetched from external APIs
    outputs/ # Processed data and results
    scripts/ # Python scripts for data processing and analysis
    utils.py # Utility functions, e.g., calculate_age
    LICENSE # Project license
    README.md # Project documentation

## Key Features

- **Data Collection**: Aggregated and cleaned international player data from various sources.
- **Age Calculation**: Implemented a utility function to calculate player ages based on birthdates.
- **Data Analysis**: Performed exploratory data analysis to identify potential scouting candidates.
- **Recommendation Engine**: Developed a scoring system to prioritize players for scouting.
